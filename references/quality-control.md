# Quality Control Checklist
## Content
- [ ] Product facts are sourced or user-provided
- [ ] Numbers include units, date and source
- [ ] Claims are not overstated
- [ ] One key message per slide

## Visual
- [ ] Typography hierarchy is consistent
- [ ] No text clipping or overflow
- [ ] Contrast and safe margins pass
- [ ] Images are high resolution and correctly cropped
- [ ] No unintended empty or duplicate slides

## Motion / Audio
- [ ] No black frames or abrupt cuts
- [ ] Animation timing is intentional
- [ ] Audio events align with visual events
- [ ] No clipping; VO intelligible
- [ ] Silent fallback exists

## Delivery
- [ ] MP4 codec / resolution / fps verified
- [ ] PPTX opens in target PowerPoint / LibreOffice
- [ ] Embedded media paths and playback tested
- [ ] Correct aspect ratio and screen map
- [ ] Asset license manifest included
