# Visual Design System
## Design tokens
每个项目必须定义：
- palette: background / surface / primary / accent / text / muted
- typography: display / heading / body / label / numeric
- spacing scale: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
- grid: columns / gutters / safe margins
- materials: matte / glass / metal / glow / gradient
- shadows and blur
- motion easing and duration

## Typography
- 使用适合目标平台的字体；优先本地可用字体。
- 中文推荐思源黑体、Noto Sans SC、HarmonyOS Sans（需确认授权和安装）。
- 英文推荐 Inter、Manrope。
- 标题使用明确层级，避免整页都使用粗体。
- 巨幕观看距离较远时提高字号与字重。

## Layout patterns
- Hero: 单一产品主体 + 一句话主张
- Split: 左文右图 / 左图右文
- Feature: 大数字 + 单个解释
- Compare: 对比双方对齐展示
- Diagram: 流程与结构关系
- Proof: 数据、来源、案例
- Gallery: 产品细节或场景矩阵
- Closing: 品牌标识 + CTA

## Accessibility
高对比度；重要信息不能只靠颜色表达；避免快速闪烁；保留字幕或演讲稿。
