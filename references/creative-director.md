# Creative Director Playbook
## 任务
把产品信息转化为发布会体验，而不是把 PRD 逐页复制到幻灯片。

## 创意简报字段
- Event title / tagline
- Product promise（一句话价值）
- Audience / audience tension
- Key proof points（每个论点对应证据）
- Emotional arc（期待→理解→惊喜→信任→行动）
- Duration / chapter plan
- Visual metaphor
- Reveal moment
- CTA

## 发布会节奏建议
- 0–10%：开场与品牌气质
- 10–25%：问题与机会
- 25–40%：核心理念与产品揭晓
- 40–70%：产品能力与演示
- 70–88%：证据、案例、商业价值
- 88–100%：发布信息与收束

## 导演检查
1. 观众能否在 3 秒内理解本页重点？
2. 视觉是否强化主张？
3. 是否有足够的停顿让观众消化？
4. 是否有一个清晰的高潮，而不是每页都高潮？
5. 是否存在未经证实的产品能力或商业承诺？
