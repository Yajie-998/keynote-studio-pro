# Widescreen & Stage Design
## Common canvases
- 4:3 1440×1080
- 16:9 1920×1080 / 3840×2160
- 21:9 2560×1080
- 32:9 3840×1080 / 7680×2160
- Custom LED pixel maps

## Rules
- Recompose per canvas; never stretch a finished 16:9 layout.
- Keep critical text and product details in a configurable safe area.
- For multi-screen stages define each screen as a named viewport with x/y/width/height.
- Avoid small body copy on distant LED walls.
- Test at actual output resolution and expected viewing distance.
- Confirm LED processor mapping, refresh rate, color pipeline and playback hardware with AV operator.
